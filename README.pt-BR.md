# Landing Pages Peritus SST

### HTML · CSS · JavaScript · calculadoras técnicas · conversão

Conjunto de **três landing pages focadas em serviços de SST**, com calculadoras interativas e continuidade comercial via WhatsApp.

## Páginas

- **Perícias Técnicas** — simula uma estimativa considerando objeto pericial, quantidade de setores e prazo;
- **Avaliações Quantitativas** — estima pontos de medição e investimento de acordo com agente, área e mobilização;
- **Revisão do FAP** — projeta o impacto financeiro usando massa salarial, RAT e FAP vigente.

## O que o projeto demonstra

- design responsivo de landing pages;
- calculadoras específicas para regras de negócio;
- componentes e utilitários compartilhados;
- formatação monetária brasileira;
- projeções e preços dinâmicos;
- validação de formulário;
- continuidade do contato via WhatsApp;
- FAQ e navegação responsiva.

## Executar localmente

```bash
cd peritus-sst
python -m http.server 8080
```

Abra qualquer uma das três páginas HTML no servidor local.

## Portfolio Edition

A versão pública utiliza contato demonstrativo e não contém leads reais, dados de clientes ou configurações privadas de campanha.
